Сборка

Заставка — При включении — Свободно под GIF —
  1. Войди в загрузчик: Настройки → Система → Обновить прошивку, или отключи паяльник, зажми OK и подключи к компьютеру.
  2. Скопируй скачанный HS02A_RU.bin на диск BOOTLOADER (на Linux — дважды, с sync).
  3. Задержка заставки: Система → GIF-заставка. Анимация при включении: Система → GIF при включении.
